Olist E-Commerce Data Analytics Project

Project Overview

This project focuses on analyzing the Brazilian E-Commerce Public Dataset by Olist to understand sales performance, customer behavior, product categories, reviews, and delivery performance.

The goal is to extract meaningful business insights and support data-driven decision-making through data analysis and visualization.

Business Objectives

- Analyze overall e-commerce sales performance.
- Understand customer purchasing behavior.
- Identify top-performing product categories.
- Analyze customer reviews and satisfaction.
- Evaluate order delivery and logistics performance.
- Identify repeat customers and business trends.

Dataset Description

The project uses the Olist Brazilian E-Commerce Public Dataset.

The dataset contains multiple tables, including:

- Customers
- Orders
- Order Items
- Order Payments
- Order Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

Tools & Technologies

- Python
- Pandas
- NumPy
- Google Colab
- SQL
- Microsoft Power BI
- Data Visualization

Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Analysis
5. Data Visualization
6. Business Insights and Reporting

Key Findings

- Total Orders: 99,441
- Total Order Items: 112,650
- Delivered Order Percentage: 97.02%
- Repeat Customers: 3,345

Dashboard

An interactive Power BI dashboard was developed to visualize important business metrics and provide insights into e-commerce performance.

Conclusion

This project demonstrates the application of data analytics techniques to real-world e-commerce data. It helps understand business performance, customer behavior, and delivery operations through data-driven insights.
